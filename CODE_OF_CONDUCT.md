# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to issues, pull requests, discussions, and every other project space, for humans and
for the agents that act for them.

In short:

- Be respectful and constructive. Critique the work, not the person.
- Do not harass, insult, or attack anyone.
- Do not publish other people's private information.
- Accept the maintainers' decisions about moderation.

## Report a problem

Contact the repository owner privately through their [GitHub profile](https://github.com/nijanthan-dev).
For a problem with a specific comment, you can also use GitHub's **Report content** option.

The maintainers review every report, keep the reporter's identity private, and can remove
content or block contributors who break this code.
